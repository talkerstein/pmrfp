# 🧭 Gamification for End Users *(muted, B2B-grade)*

Each side of the marketplace gets a tier ladder with real economic value. Visual
treatment is intentionally restrained — typography only, no medals, no colors,
no level-up animations. The reference aesthetic is LinkedIn "All-Star" / GitHub
commit graph / Stripe Atlas alumni page. Not Duolingo, not Reddit, not Pokemon.

## The Trade Ladder

Uses native trade-cert vocabulary. Visible to trades as one dashboard line
(`Tier: Foreman · 1 step to Master →`). Visible to PMs as a small typographic
mark beneath the company name on directory cards.

| Tier | How to reach it | Real benefit |
|---|---|---|
| Apprentice | Free signup | Directory listing only. No RFP access. |
| Journeyman | $249/yr Pro | Full RFP feed. Express interest. Standard ranking. |
| Foreman | Pro + 100% profile + insurance verified + ≥3 interests submitted | Priority placement on category pages. 12-hr early-access window on matching RFPs. |
| Master | Foreman + Featured $599 OR ≥10 verified referrals OR 12 mo tenured | Top 3 slots on category pages. Dedicated CSM. Quarterly co-marketing post. Free year of PermitClub. |
| Elite | Invite-only — case study + industry leader | Founding-member status. Roadmap voting. Lifetime price lock at $249. Press intros. |

**Visual treatment — asymmetric, panel-verdict (2026-05-31).** Restraint at low
tiers, distinction reserved for top tiers. The whole visual story for the entire
gamification system is: typography + an occasional 1-line hairline rule. No
colored circles. No icons. No animations. No level-up toasts.

| Tier | Visual treatment |
|---|---|
| Apprentice, Journeyman | No visible tier mark anywhere. Tier exists on backend only. |
| Foreman | Pure typography. `FOREMAN` in IBM Plex Mono small caps, color `--ink-3` (muted gray), beneath company name. |
| Master | Typography + one thin teal hairline rule (max 12 px wide, `--teal-ink`). Wordmark `MASTER` in same small-caps treatment. |
| Elite | Typography + one thin indigo hairline rule (`--indigo`). Wordmark `ELITE`. The indigo vs teal is the only visual distinction between Master and Elite. |

## The PM Ladder

Uses real-estate vocabulary. Visible to the PM in their dashboard header. The
"Trusted PM" hairline label becomes visible to trades on the PM's RFPs at
Director and above.

| Tier | How to reach it | Real benefit |
|---|---|---|
| Steward | Free signup | Browse + post. |
| Operator | 1 RFP posted | Saved-vendors list. Interest notifications. |
| Director | 5 RFPs + ≥1 closed-loop "awarded" update | Trades see "Trusted PM" label → meaningfully more interest. Vendor analytics. Priority support. |
| Principal | 20+ RFPs OR portfolio account (5+ active buildings) | API access. PDF/CSV vendor-response export. White-glove team onboarding. Free insurance verification on awarded vendors (we cover $20-50). |
| Patron | Invite-only — case study + advisory | Named in case studies. Advisory board seat. Lifetime free for the entire org. |

## Three constraints the panel agreed on

1. **Opt-out toggle** — any user can hide their tier mark via Settings. Tier
   logic still affects ranking/access on the backend; the UI mark is the
   user's choice. (Working PM + Client Advocate)
2. **Tier vocabulary stays industry-native** — Apprentice through Master maps to
   real trade certifications; Steward through Patron uses real-estate governance
   language. Never invent vocabulary that insults experienced users (a 20-year
   journeyman labeled "Apprentice" because they just signed up = leaves
   immediately). (Construction Expert + Real Estate Expert)
3. **No animations, toasts, or sounds** — tier change happens silently. User
   discovers it on next dashboard load. Reference aesthetic: LinkedIn
   "All-Star," GitHub commit graph, Stripe Atlas alumni page, Bloomberg
   Terminal — NOT Duolingo, Reddit, or Pokemon. (Brand Strategist + Enemy)

## What the tier system is NOT

- Not visible in v1 (tiers exist on the backend; UI surfaces marks once the
  underlying quests are done — otherwise pointing at a "Foreman" tier that
  doesn't unlock anything is worse than not having tiers)
- Not gamification for its own sake — every tier above the free one delivers
  more leads, more visibility, or more time-savings. Vanity-only badges are
  insulting in B2B
- Not driven by visuals — the unlock structure does the behavioral work.
  The typography is just the reward signal, restrained on purpose so a senior
  buyer landing on the directory doesn't think "is this Yelp?"
